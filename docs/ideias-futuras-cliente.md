# Ideias futuras do cliente

Ideias registradas para discussão e planejamento; ainda não implementadas.

- **Confirmar recebimento:** oferecer ao cliente um botão para informar que recebeu
  o pedido. Definir com a equipe como essa confirmação se relaciona com a
  conclusão feita pelo motoboy, inclusive quando houver divergência.
- **Atendimento / SAC:** permitir relatar problemas como item faltando, pedido
  incorreto ou outro problema. Definir categorias, descrição, responsáveis,
  tratamento pela proprietária e eventual histórico antes de implementar.
